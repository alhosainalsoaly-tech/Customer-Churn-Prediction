# Customer Churn Prediction

## About the Project

This is a simple Data Science and Machine Learning project that predicts whether a customer is likely to leave a company.

The project uses customer information such as age, monthly charges, and tenure to make the prediction.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn

## Project Steps

1. Create and explore the dataset.
2. Check for missing values.
3. Prepare the data.
4. Split the data into training and testing sets.
5. Scale the features.
6. Train a Logistic Regression model.
7. Make predictions.
8. Evaluate the model.

## Model

The project uses Logistic Regression to predict customer churn.

The model is trained using the prepared customer data and then tested on unseen data.

## Evaluation

The model performance is evaluated using:

- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## Goal

The main goal of this project is to practice the basic steps of a Data Science and Machine Learning workflow using a simple real-world business problem.
